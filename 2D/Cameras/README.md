# 2D Camera Index

The canonical camera guides are in the singular Camera folder:

- [Follow and pixel-perfect setup](../Camera/Camera-Follow-and-Pixel-Perfect.md)
- [Camera bounds](../Camera/Camera-Bounds.md)
- [Screen shake](../Recipes/Screen-Shake.md)

Use an orthographic camera for most 2D games. Orthographic Size is half of the vertical view span. Keep follow, clamping, and shake movement coordinated so multiple scripts do not overwrite the same Transform.
